# حاسبة آجل باي

مشروع ويب عربي بسيط لمقارنة سعر المنتج عند السداد المباشر مع إجمالي السعر عند استخدام آجل باي، مع توضيح فرق القيمة وقيمة كل دفعة.

## فكرة المشروع

يحتاج العميل قبل اتخاذ قرار الشراء إلى معرفة الفرق بصورة واضحة ومباشرة. تحول الحاسبة سعر المنتج إلى مقارنة سهلة الفهم دون الحاجة إلى التسجيل أو إدخال بيانات شخصية.

## الخصائص

- حساب سعر السداد المباشر.
- حساب إجمالي السعر عبر آجل باي.
- توضيح فرق القيمة بين الخيارين.
- حساب قيمة الدفعة الواحدة.
- إمكانية تعديل نسبة عمولة آجل باي وعدد الدفعات.
- تصميم عربي متجاوب مع الجوال والكمبيوتر.
- تنبيه واضح بأن النتائج تقديرية.
- لا تجمع الأداة أي بيانات شخصية.

## المعادلة المستخدمة

```text
قيمة المنتج = إجمالي آجل باي - عمولة آجل باي
عمولة آجل باي = إجمالي آجل باي × نسبة العمولة
إجمالي آجل باي = قيمة المنتج ÷ (1 - نسبة العمولة)
فرق القيمة = إجمالي آجل باي - قيمة المنتج
قيمة الدفعة = إجمالي آجل باي ÷ عدد الدفعات
```

نسبة العمولة الافتراضية في النسخة الحالية هي 20% من إجمالي قيمة آجل باي، ويمكن تعديلها من واجهة الحاسبة.

## مثال

إذا كانت قيمة المنتج 1,000 ريال وعمولة آجل باي 20% من إجمالي قيمة آجل باي:

- السداد المباشر: 1,000 ريال.
- فرق القيمة وعمولة آجل باي: 250 ريال.
- إجمالي آجل باي: 1,250 ريال.
- عند اختيار 4 دفعات: 312.50 ريال لكل دفعة.

## تشغيل المشروع محليًا

يمكن فتح ملف `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي بسيط.

## النشر عبر GitHub Pages

1. أنشئ مستودعًا جديدًا باسم `ajel-pay-calculator`.
2. ارفع ملفات المشروع إلى الفرع `main`.
3. افتح `Settings` ثم `Pages`.
4. اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/root` ثم اضغط `Save`.
